# Companion planning

The phase list is approved. The user learns the feature by planning it with you. Forms are in `phase-formats.md`.

## One try per level

Work through the phases in order. UI, readiness and acceptance phases you write yourself and present for comment. Each code phase takes one round for Level 2, then one for Level 3:

1. Give the material for that level. Level 2: the objective and its context. Level 3: empty shells, each a function's name, signature and purpose, plus `file:line` pointers to where its inputs live.
2. The user sends an outline.
3. Write the final version into the plan. List anything that differs from the outline, and why.

One try is the limit. An open requirement goes to the user as a `grilling` question and doesn't count as the try.

Done when every code phase has its final Level 2 and Level 3.
