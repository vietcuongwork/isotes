# Companion planning

The phase list is approved. The user learns the feature by planning it with you. Forms are in `phase-formats.md`.

## One try per phase

Work through the phases in order. UI, readiness and acceptance phases you write yourself and present for comment. Each code phase takes one round:

1. Give the Level 2 material top-down: entry point or route, screen, hook, component, helpers, then where the data is seeded, with the data flow drawn in one line. For each objective, its context and `file:line` pointers to where its inputs live.
2. The user sends an outline, with pseudo code where they have it.
3. Write the final Level 2 and its Level 3 tasks into the plan from that outline. List anything that differs from the outline, and why.

One try is the limit. An open requirement goes to the user as a `grilling` question and doesn't count as the try.

Done when every code phase has its final Level 2 and its tasks.
